# ForestDynamics

**홍천군 기온·강수량과 위성영상 NDVI의 공간·시간적 관계 분석**  
*Spatiotemporal Analysis of Climate Variables and Satellite-Derived NDVI in Hongcheon, South Korea*

## 1. 프로젝트 개요

이 프로젝트는 강원특별자치도 홍천군의 공간 분석 구역을 대상으로 **월평균 기온**, **월누적 강수량**, **월평균 NDVI** 사이의 분포와 상관관계를 분석한다.

산림청 임상도에서 만든 벡터 구역을 분석 단위로 사용하며, **Google Earth Engine(GEE)에서 ERA5-Land 기상 래스터와 Sentinel-2 위성영상을 처리해 구역별 통계값을 추출**하였다. 래스터 파일 전체를 내려받아 로컬에서 결합한 방식이 아니라, GEE를 이용해 계산한 결과를 표 형태로 수집·병합한 방식이다.

이 저장소에 기록된 작업은 **공간 데이터 구성, 기후·NDVI 자료 취합, 기초통계, 결합상대도수 및 상관분석**이다. 인과효과 추정이나 미래 식생 예측 모델은 현재 결과에 포함하지 않는다.

| 항목 | 내용 |
| --- | --- |
| 연구 지역 | 대한민국 강원특별자치도 홍천군 |
| 분석 기간 | 2017–2025년, 매년 6·7·8월 |
| 관측 단위 | 공간 구역 × 연도 × 월 |
| 공간 구역 수 | **2,005개** |
| 전체 가능한 관측 조합 | 2,005 × 9년 × 3개월 = **54,135개** |
| 최종 통계 분석에 사용한 행 | **50,771개** (`정제자료` 시트; NDVI 결측 제외) |
| NDVI 유효면적 80% 기준 통과 행 | **46,048개** (별도 품질 필터를 통과한 자료) |

> **용어 주의:** 최종 통계 Excel의 `원자료`(46,048행)와 `정제자료`(50,771행)는 이름과 달리 동일한 필터를 적용한 전후 자료가 아니다. 분석에 실제 사용한 값과 NDVI 품질 기준 통과 자료를 구분하여 해석한다.

## 2. 데이터 출처

| 자료 | 출처 | 사용 목적 |
| --- | --- | --- |
| 임상도 | 산림청 **산림공간정보서비스**, 산림공간자료 유통신청으로 확보한 홍천군 `51720.shp` | 분석 구역의 원본 도형 |
| 기온·강수량 | [ECMWF ERA5-Land Daily Aggregated](https://developers.google.com/earth-engine/datasets/catalog/ECMWF_ERA5_LAND_DAILY_AGGR) | 지상 2 m 공기 온도, 총강수량 |
| 위성영상 | [Sentinel-2 Surface Reflectance Harmonized](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED) | B4·B8·SCL 밴드 기반 NDVI 계산 |

- **지상 2 m 기온**은 지면 위 약 2 m 높이의 공기 온도를 의미하며, 2 m 해상도의 래스터라는 뜻이 아니다.
- ERA5-Land의 기온값은 **K → °C**로 변환하고, 일별 강수량은 월별로 합산한 뒤 **m → mm(×1,000)**로 변환하였다.
- ERA5-Land는 기상 재분석자료이며 개별 산림 구역에 설치된 온도계·강수계의 직접 측정값은 아니다.
- 임상도의 정확한 수령 판본·날짜와 **원본 및 파생 공간자료의 재배포 허용 범위**는 공개 전에 확인해야 한다. 원본 SHP는 현재 첨부 산출물과 별도로 보관된다.

## 3. 공간 분석 구역 구성

`51720.shp`의 원본 도형을 **EPSG:5179** 좌표계에서 처리해 1 km 격자 기반의 분석 구역을 만들었다.

1. X·Y 격자 경계가 각각 1,000 m의 정수배가 되도록 **1 km × 1 km** 격자를 정렬한다. 이는 좌표계 원점을 변경한다는 의미가 아니라 격자선의 위치를 일정하게 정한다는 의미다.
2. 원본 도형과 격자를 교차시킨다.
3. 같은 격자에 해당하는 조각을 통합하고 `구역_ID`를 부여한다.
4. `forest_split_1km` 레이어를 GeoPackage(`.gpkg`)로 저장하고 QGIS 프로젝트(`.qgz`)로 확인한다.

업로드한 `split_report.json`과 GPKG를 기준으로 확인한 값은 다음과 같다.

| 검증 항목 | 값 |
| --- | ---: |
| 입력 피처 | 76,479 |
| 출력 분석 구역 | **2,005** |
| 입력 도형 면적 합 | 1,525,798,527.223 m² |
| 출력 도형 면적 합 | 1,525,798,527.213 m² |
| 중복 `구역_ID` | 0 |
| 유효하지 않은 출력 도형 | 0 |

**중요한 분류 조건:** `split_report.json`은 `classification_filter: "none; all original classes retained"`라고 기록한다. 따라서 이 공간자료를 '특정 산림 수종 분류만 추출한 구역'이라고 소개하지 않는다. 산림 피복만을 대상으로 엄격히 분석하려면 해당 분류 조건을 다시 검토해야 한다.

QGIS 프로젝트는 아래 상대경로로 GPKG를 참조한다. **QGZ와 GPKG를 같은 디렉터리**에 놓아야 한다.

```text
./hongcheon_split_1km.gpkg|layername=forest_split_1km
```

## 4. 기상 래스터 처리

ERA5-Land의 기온·강수량 값을 구역·연도·월 단위로 집계하였다.

- **월평균기온(°C):** 해당 월의 일별 2 m 공기 온도를 평균하고 K에서 °C로 변환
- **월누적강수량(mm):** 일별 강수량을 월별로 합산하고 m에서 mm로 변환
- **공간 대응:** 기상 래스터 셀과 산림 분석 구역의 **교차 면적**을 가중치로 사용하여 구역별 값을 산출
- **강수량 보정:** 자료 처리 과정에서 확인된 미세한 음수 일강수량을 0으로 보정한 이력이 있음

기상 래스터의 픽셀과 1 km 산림 분석 구역이 반드시 일치하는 것은 아니므로, 단일 픽셀의 값을 그대로 복사하는 대신 구역에 겹치는 면적을 반영하였다.

기상자료 결과 예시인 `gee데이터.xlsx`에는 다음 열이 확인된다.

```text
구역_ID, 연도, 월, 자료일수, 월평균기온_C, 월누적강수량_mm,
산림면적_m2, 기온_유효면적비율, 강수_유효면적비율,
음수강수_포함여부
```

> `gee데이터.xlsx`가 **음수 강수량 보정 이전 또는 이후 어느 버전인지**는 최종 계산값과 대조해야 한다. 그 파일을 단순히 다시 읽는 것만으로 최종 보정 결과까지 완전히 재현된다고 보장하지 않는다.

## 5. Sentinel-2 NDVI 산출 및 병합

### 5.1 GEE 래스터 계산

사용한 NDVI 수집 코드의 핵심 설정은 다음과 같다.

| 항목 | 설정 |
| --- | --- |
| 영상 컬렉션 | `COPERNICUS/S2_SR_HARMONIZED` |
| 분석 기간 | 2017–2025년, 6·7·8월 |
| NDVI 밴드 | 적색 **B4**, 근적외선 **B8** |
| SCL 허용 분류 | **4(식생), 5(비식생 지표), 6(물)** |
| NDVI 처리 격자 | **EPSG:32652**, **10 m** |
| 최소 유효 관측 수 | `MIN_VALID_OBS = 1` |
| 유효면적 품질 기준 | `MIN_COVERAGE = 0.80` |
| GEE 요청 배치 | 산림 구역 50개씩 |

NDVI는 다음과 같이 계산한다.

\[
\mathrm{NDVI}=\frac{B8-B4}{B8+B4}
\]

GEE에서 수행한 작업:

1. Sentinel-2 지표반사율 영상의 B4·B8을 이용해 NDVI를 계산한다.
2. SCL 마스크로 지정된 분류 외의 픽셀을 제외한다.
3. 각 픽셀의 **월평균 NDVI**와 유효 관측 수를 계산한다.
4. GEE `reduceRegions`를 사용해 **분석 구역별 유효 픽셀 면적가중 평균 NDVI**와 품질 지표를 구한다.
5. 반환된 구역별 통계값을 CSV 캐시에 보관하고 DataFrame으로 통합한다.
6. 기상자료와 `구역_ID`, `연도`, `월`을 키로 병합한다.

이때 **원본 위성영상 전체를 로컬로 다운로드한 것이 아니다.** GEE 서버에서 래스터를 계산하고 구역별 결과를 받아온 것이다. 관측이 없는 위치의 NDVI는 0으로 대체하지 않고 결측으로 유지한다.

### 5.2 생성되는 DataFrame

| 이름 | 의미 |
| --- | --- |
| `ndvi_df` | 구역·월별 NDVI와 관측 품질 지표 |
| `combined_df` | NDVI와 기온·강수량을 합친 전체 테이블 |
| `analysis_df` | NDVI 값 존재, 유효면적비율 80% 이상, 기온·강수값 존재를 모두 충족하는 행 |

`analysis_df`의 80% 기준은 코드에 설정한 **분석용 필터**이며, 모든 데이터셋에 공통으로 적용된 기준은 아니다.

### 5.3 백업 및 Excel 저장

제공된 별도 Colab 코드에서는 `combined_df_backup`과 `analysis_df_backup`을 메모리에 복사한 뒤 다음 파일을 생성했다.

```text
홍천_기온_강수_NDVI_병합완료.xlsx
├── 전체자료   ← combined_df
└── 분석자료   ← analysis_df
```

Excel 저장에는 `pandas.ExcelWriter(..., engine="openpyxl")`을 사용하고, 첫 행 고정·자동 필터·열 너비 설정을 적용했다. `*_backup` 변수는 **Colab 런타임 안의 복사본**이므로 영구 백업이 아니며, 파일 다운로드 후 별도로 저장해야 한다.

## 6. 통계 분석 결과

별도로 작성한 **`202510124최재민 통계적분석 프로젝트1차 과제 (1)(2).xlsx`**에는 연구 배경, 데이터 출처, 기초통계, 산점도, 결합상대도수, 상관계수 및 한계가 정리되어 있다.

**통계 분석 기준:** `정제자료` **50,771행**. 이 집합은 NDVI 결측을 제외한 자료로, 위의 **80% 유효면적 품질 기준 통과 46,048행**과 구분해야 한다.

| 변수 쌍 | 전체 피어슨 상관계수 (*r*) |
| --- | ---: |
| 월평균기온 – 월평균 NDVI | **−0.1656** |
| 월누적강수량 – 월평균 NDVI | **−0.2066** |
| 월평균기온 – 월누적강수량 | **+0.2313** |

기온–NDVI 상관관계는 월별로 차이를 보였다.

| 월 | 기온–NDVI 상관계수 (*r*) |
| --- | ---: |
| 6월 | −0.2370 |
| 7월 | +0.1510 |
| 8월 | −0.0115 |

이 결과는 전체 상관계수를 여름철 모든 달에 동일하게 적용해 해석하기 어렵다는 점을 보여준다. **상관관계는 인과관계가 아니며**, 산림 고사나 미래 식생 쇠퇴를 직접 입증하는 결과도 아니다.

## 8. 실행 환경 및 재현 방법

### Python 패키지

**현재 제공된 NDVI 수집·병합 코드와 Excel 내보내기 코드**의 직접 외부 의존성은 다음과 같다.

```text
earthengine-api
numpy
pandas
openpyxl
```

공간자료를 **GeoPackage에서 직접 읽어 `zones`로 생성하는 준비 셀**에는 `geopandas`도 필요하다. 해당 준비 단계를 저장소에 포함한다면 `requirements.txt`에 `geopandas`를 추가한다. Python 표준 라이브러리(`json`, `time`, `pathlib`, `hashlib`)와 Colab 제공 모듈(`google.colab`)은 별도로 나열하지 않는다.

### 재현 순서

1. Colab에서 필요한 패키지를 설치하고 GEE 인증·프로젝트 초기화를 완료한다.
2. `hongcheon_split_1km.gpkg`를 `GeoDataFrame`으로 불러와 **`zones`** 변수를 준비한다.
3. ERA5-Land로 집계한 기상표를 **`weather_df`** 변수로 준비한다. 필요한 필드는 `구역_ID`, `연도`, `월`, `월평균기온_C`, `월누적강수량_mm`이다.
4. 동일한 Python 런타임에서 **NDVI 수집·병합 코드**를 실행한다.
5. 백업·Excel 내보내기 코드를 실행하여 결과를 저장한다.

`zones`를 만드는 과정의 예시는 다음과 같다.

```python
import geopandas as gpd

zones = gpd.read_file(
    "data/spatial/hongcheon_split_1km.gpkg",
    layer="forest_split_1km",
)
```

기상 표가 **이미 최종 보정된 파일**로 제공된다면 `pandas.read_excel(...)`로 `weather_df`를 준비할 수 있다. 단, 실제 파일의 시트명·열 이름·보정 상태를 확인해야 한다. 이 단계가 자동화되어 있다고 가정하지 않는다.

**재현성의 현재 한계:** 제공된 NDVI 스크립트는 `zones`와 `weather_df`가 **이미 존재해야 시작할 수 있다.** 초기 임상도 격자 생성 및 ERA5-Land 기상자료 수집·보정의 전체 코드는 이번에 제공된 NDVI 스크립트에 포함되어 있지 않다. 따라서 이 README는 현재 산출물과 부분 실행 절차를 문서화한 것으로, 새 환경에서 **단일 명령만으로 전체 프로젝트가 재현됨을 보장하지 않는다.**

## 9. 분석의 한계 및 향후 방향

- 연구 지역은 홍천군, 분석 시기는 6–8월로 제한된다.
- 구름·그림자 등의 영향으로 NDVI 관측 결측 및 유효면적 차이가 발생한다.
- Sentinel-2와 ERA5-Land의 공간해상도가 서로 다르며, 여러 구역이 같은 기상 셀 값을 공유할 수 있다.
- 동일한 구역을 여러 해 반복 관측했으므로 모든 관측 행을 통계적으로 독립이라고 볼 수 없다.
- 원본 임상도의 분류가 모두 유지된 공간 구역이므로 산림 피복 선택 기준의 적합성을 추가로 검토할 필요가 있다.
- 고도·수종·토양·누적 강수·시차 효과 등을 별도로 모형화하지 않았다.

향후에는 **품질 기준별 민감도 분석**, **시차를 고려한 기후–NDVI 분석**, **시간순 평가를 이용한 식생 상태 예측**으로 확장할 수 있다. 이는 현재 완료한 작업이 아닌 후속 연구 계획이다.
